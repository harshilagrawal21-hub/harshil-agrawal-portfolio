# Harshil Agrawal — Portfolio Starter

A responsive personal portfolio built with HTML, CSS and JavaScript.

## Run locally
1. Download and extract the ZIP.
2. Open `index.html` in a browser.

## Before publishing — personalize it
Search the files for `YOUR_` and replace:
- `YOUR_EMAIL@example.com`
- `YOUR-LINKEDIN`
- `YOUR-GITHUB`

Also review the Career Launcher entry and add your exact role, dates and responsibilities. Add public links/screenshots to project work where possible. Remove anything that does not accurately represent you.

## Deploy with GitHub + Vercel
1. Create a GitHub account if you do not already have one.
2. Create a **public** repository named `harshil-agrawal-portfolio`.
3. Upload `index.html`, `style.css`, `script.js`, and `README.md` to the repository root.
4. Commit the files from your own GitHub account with a meaningful message such as `Create initial portfolio`.
5. Sign in to Vercel with GitHub and import the repository.
6. Deploy using the default settings. No build command is needed; the site is static.
7. Test the live site on desktop and mobile.
